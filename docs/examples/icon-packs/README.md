# Pacotes de ícones de exemplo

`cores-lisas` é um pacote completo e pequeno: placas lisas com a inicial do programa, desenhadas para este projeto. Serve para ver o formato funcionando e como ponto de partida.

Para usar, copie a pasta `cores-lisas` para `%APPDATA%\dev.maxsueleinstein.dockmax\IconPacks\` (o botão **Abrir pasta de pacotes**, em Configurações › Aparência do dock › Ícones dos apps, abre essa pasta) e escolha **Recarregar pacotes**.

O formato do `pack.json`, os limites e as regras de segurança estão na [spec 0007](../../specs/0007-fase-b4-icones.md).
